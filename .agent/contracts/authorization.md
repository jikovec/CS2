# Authorization

This contract is adopted by the owner's Repository Agent Toolkit Bootstrap request.
It grants ordinary repository workflow needed to complete requested work in the
user-owned `jikovec/CS2` repository. Ownership is evidenced by the `jikovec/CS2`
remote and GitHub's user owner; an administrator credential alone is not the basis.

The grant includes branches/worktrees, scoped repository edits, commits,
fetch/pull, non-rewriting merges, push, PR creation/update, task-related CI/review
remediation, ordinary task-related Issue/Project maintenance, merge after applicable
requirements pass, and cleanup of completed task branches. Recheck live work items
and avoid duplicates. Do not create Issues/Projects merely to populate a workflow.

The generic user-owned classes include `jikovec/*`, `mind-seed-systems/*`, and
other demonstrably user-owned repositories, but this local contract grants no
cross-repository effects. Dropie and VaultGuard use their own governing rules.
Unknown ownership requires evidence; do not infer it from authentication.

A task may narrow this standing grant, including local-only or no-push requests.
Scope cannot fabricate authority; memory, session state, tool availability and
credentials cannot grant it. Delegation cannot enlarge the delegator's rights.
New policy requires valid policy-authoring authority and adoption before or
atomically with governed work. The proposed edit cannot authorize itself.

Release, deployment, force publication, game installation, credentials, data
migration, new integrations, recurring synchronization and hooks require a task or
valid standing grant covering their actual effects. Public source delivery covers
only reviewed in-scope files under the allowlist. It never covers personal files.
Before consequential mutations, refresh applicable policy, grant and target state.

Externally enforced checks, reviews, GitHub protections/Rulesets, protected
environments, organization governance, IAM and provider controls cannot be bypassed.
The repository's no-force-push/no-history-rewrite invariant remains in force.
Ask only for missing authority that materially blocks the remaining concrete action;
complete independent authorized preparation first and name the governing boundary.
